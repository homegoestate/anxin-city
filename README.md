# 宏國・易丞｜不動產安心城

公開體驗網址：https://homegoestate.github.io/anxin-city/

版本：5.0.0。原創 Three.js 互動城市，包含四位居民的人生任務，以及「台南散步集章」37區地方探索。任務可重選比較、在同一裝置續玩，並帶著可編輯的虛構情境摘要前往官方 LINE。

## 使用方式

點首頁「選一位居民，開始玩」、上方「人生任務」，或城市裡有名字的居民。每位居民有四個選擇，每次選擇會更新影響；結局可返回任一步比較。城市可拖曳旋轉、滾輪縮放；手機可單指旋轉、雙指縮放。

- 首購小安：生活與看房需求、總價、準備時間、收入或利率壓力；顯示進場缺口、月付及生活餘額。
- 換屋阿成：先買／先賣／協調交屋、出售時間、假設融資與備案；同一16個月區間比較月內缺口、雙房貸、租屋與搬家。
- 賣屋美玲：開價、等待、議價與示意稅款預留；檢查交屋前現金及成交後淨額。
- 傳承一家：比較生前贈與／日後繼承，再盤點照顧、家人與時間。稅目流程及500萬元現金案例有完整假設與官方來源；不把市價直接當作房地稅基。

「給點建議」可提交匿名意見，成功收件會顯示編號。意見儲存在獨立回饋服務，無公開查詢介面。這個儲存庫不含回饋紀錄、後台權限或密鑰。

## 官網與 LINE 整合

「官網・LINE」提供公司官網、實用工具、既有 LINE 關鍵字與七組主題影片。任務結局依人物提供房貸、稅務或傳承服務入口。LINE 摘要由使用者修改並自行送出，不會自動上傳。

首購可調整年齡、收入、存款、生活費、其他月付、貸款比例、年利率與年限；傳承可調整年齡、照顧現金、專用收入與預留月份。年齡只作期間加總；傳承設定不改變獨立的500萬元現金稅務案例。主要內文16px，A＋模式18px並儲存在同一瀏覽器。

網址 `?start=first-home`、`move-home`、`seller`、`legacy-family`、`tainan`、`policy`、`services` 可直接進入指定內容；未知值保持城市首頁。官網首頁與共用導覽提供安心城入口。

## 台南散步集章

點首頁「台南散步」，或城市中的海線、府城、平原、山城標牌。四個小島以鹽田與濕地、紅磚城門、稻田蓮池、芒果山城為意象；分組是探索主題，不是官方分區或精準地圖。

- 37區各有地方特色、常見時節、三選一小知識與生活觀察建議；答對可集章，選錯可重試。
- 印章僅存於目前瀏覽器，重複答題不重複累加；換裝置或清除資料不會同步。不收集定位或真實居住資料。
- 8張四季風物卡可依月份篩選，包括芒果、文旦、元宵、蓮花、木棉、蘭花、候鳥及梅花。月份為一般時節，非年度活動行事曆。
- 6項地方發展與公共服務資料，逐項列出官方來源、發布／生效／查核日期與階段。查核日2026/10/25，人工整理，不會自動更新；超過90天會顯示更新提醒。
- 地方卡可接回首購小安任務；四位居民的任務結局也可前往散步。各區回饋帶上地方名稱，送往原有私有回饋服務，方便後續分類。

新青安政策核對日期：2026/10/25；其餘房貸政策核對：2026/10/24；傳承稅務核對：2026/10/25。數字、貸款成數、收入與生活費均為教學假設，不判定個案核貸資格。未作答項目暫用第一選項預覽，已在情境假設逐項揭露。未串接正式案件、預約或 LINE 身分系統。

LINE 的「安心城」關鍵字提供六個入口，既有「官方服務」「新青安」「貸款規定」維持原規則。新入口獨立維護於 nexus-line-bot，不在這個靜態網站儲存庫。

LINE 入口為宏國官方帳號 `@604gpqef`，僅建立由使用者點擊的預填文字連結，不自動傳訊。手機需安裝 LINE；電腦可複製摘要，再使用官方帳號 QR Code。開啟 LINE 與實際送出須由使用者在裝置上完成。遊戲選擇只保留在 localStorage，不會隨回饋自動上傳。

## 計算與內容邊界

- 本息平均攤還、固定利率、無寬限期；數字四捨五入至元。利率增加情境重算整筆新貸款，並非既有貸款調息精算。
- 換屋每月先計日常收支與貸款，再於月底交屋；新房貸自購屋次月開始。尚未核准的短期融資不視為已到位資金，利息另列。最高缺口包含保留60萬元預備金，與期末現金不同。
- 賣屋稅款預留為50／100／150萬元練習輸入，不是房地合一稅或土增稅實算。
- 傳承照顧現金與稅務案例分開。500萬元現金贈與案例，贈與人另備25.6萬元稅款；500萬元全部應計遺產案例在完整假設下遺產稅為0。比較相同移轉財產，非相同總支出或終身稅負。
- 角色不是真實客戶。遊戲不代替產權、銀行、稅務、契約與家庭情況的完整查核。

## 維護

GitHub Pages 從 main 分支根目錄發布，無建置步驟。請透過 HTTP 伺服器預覽；不要直接以 file:// 開啟含 ES Modules 的頁面。

- `city.js`：程序化立體城市與居民動態。
- `app.js`：旅程、準備清單與城市控制。
- `enhancements.js`：居民故事、試算與回饋表單。
- `policy-data.js`：政策內容、查核日期與官方來源。
- `loan.js`：月付計算。
- `scenario-profile.js`：可調整欄位與明確的數值驗證。
- `service-hub.js`、`video-links.js`：官網、LINE、影片及任務接續入口。
- `readability.css`：舒適／大字模式與手機排版。
- `game-engine.js`：純函式分支與現金流計算；返回修改時從完整答案重算。
- `game-ui.js`、`game.css`：四步任務、後果、重選比較、續玩與 LINE 摘要。
- `legacy-policy.js`：官方稅務來源、適用條件與比較案例。
- `assets/residents-v3.png`：為本案生成的原創四組角色插畫。
- `tainan-data.js`：37區、8張季節卡與16個官方地方資料來源。
- `tainan-updates.js`：6項人工查核的發展與政策快照；更新時重新確認階段與日期。
- `tainan-state.js`：集章保存、搜尋與答題的純函式。
- `tainan-ui.js`、`tainan.css`：地方探索、原創景觀插畫、月份篩選、集章冊與任務入口。

Three.js r180 檔案與 MIT 授權位於 `vendor/`。其餘網站視覺與程式為本案原創，未使用參考網站的程式或模型。
